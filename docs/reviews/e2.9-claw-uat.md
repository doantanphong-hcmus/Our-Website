# E2.9 — Máy gắp thú: test và UAT

Trạng thái tự động: **đạt**. Trạng thái thiết bị thật: **chờ chủ sản phẩm chạy và ký xác nhận 20 lượt**.

| Gate | Bằng chứng tự động |
|---|---|
| Physics invariants | 20 seed được replay hai lần; kết quả, số bước, capture và sáu body phải hợp lệ |
| Kỹ năng thay vì gacha | Cùng seed nhưng vị trí canh khác có cả thắng lẫn trượt; giảm lực bám đổi thắng thành trượt |
| Permission / thiếu tài nguyên | Integration chặn Nam mua/chơi, chặn mua khi thiếu sao và tạo lượt khi hết credit |
| Double tap / retry | Hai request mua, tạo attempt và complete đồng thời chỉ ghi một giao dịch, một thú và một quà |
| Reload / offline / realtime | Trace được phục hồi, completion chờ được gửi lại, timeout rõ ràng và hai tài khoản nhận `claw.updated` |
| Mobile / accessibility | Smoke test ở 360px và 430px; dark, reduced-motion, nút âm thanh–rung và không tràn ngang |

Chạy bằng `npm test`, `npm run realtime:check`, sau đó chạy `npm run web:preview` và `npm run web:check` ở terminal khác.
